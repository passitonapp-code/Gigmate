# GigMate prototype

A phone-first static web app prototype for discovering gigs, saving events and planning with friends.

## Run locally
Open `index.html` in a browser. For PWA installation and service-worker support, serve the folder over HTTPS (or localhost).

## Publish
Create a GitHub repository, upload the contents of this folder to the repository root, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Install on a phone
- Android: open the published HTTPS site in Chrome → menu → Install app / Add to Home screen.
- iPhone: open in Safari → Share → Add to Home Screen.

## Prototype limitations
Event listings are sample data. There is no live event feed, Spotify integration, account system, cloud sync, real friend invitations, ticket checkout or push notifications. Saved gigs are stored locally in the browser. This is a web app/PWA prototype, not a native Android APK or iOS IPA.
